# Changelog

All notable changes to Newspaper are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/) and the
project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-10

### Added
- Initial release: a newsprint theme with black ink, heavy rules, uppercase section bars and a red spot color.
- Support for Redmine 7+ (`themes/` directory).
- Header, login and favicon artwork.
